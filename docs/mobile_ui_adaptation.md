# 移动端界面适配

## 目标

让内容工作台、求职助手、面经库和技能库在手机竖屏、手机横屏及平板上保持可阅读、可滚动、可触达；不改变既有 API、任务流或发布逻辑。

## 设计取舍

- 移动端采用单一主滚动面：桌面侧栏收为抽屉，正文页面承担纵向阅读，避免多个嵌套滚动区争夺手势。
- 保留职业工作台既有的绿色轨道视觉；登录页在窄屏降低轨道装饰权重，让标题和认证动作优先可见。
- 横屏手机恢复为紧凑双栏，避免认证表单被桌面转单列规则推到两屏之外。
- 底部 Sheet、模型连接和面经导入表单均使用 `dvh` 与安全区内边距，保证 iPhone 手势区域不遮挡按钮。

## 调用链与影响范围

`App.vue` 的路由壳层 → `styles.css` 的导航抽屉、顶部栏、工作台/技能库通用响应式规则 → `CareerAssistantPage.vue` 与 `InterviewLibraryPage.vue` 的页面级布局和弹窗规则。

本次只修改前端样式，不触碰模型调用、数据库、文档解析、Skills 搜索或微信公众号发布逻辑。

## 验证

- `cd web-ui && npm run build` 通过。
- 本地登录页在 `390×844` 下无横向溢出。
- 本地登录页在 `896×414` 横屏下文档高度与视口高度一致，提交按钮位于首屏内。
- 业务页需要已登录会话后继续进行真机验收：导航抽屉、模型连接 Sheet、面经导入 Sheet、长会话输入区和技能编辑区。

## 边界

本次不新增移动端专用路由，也不在未认证状态下绕过平台登录来伪造业务页测试会话。
