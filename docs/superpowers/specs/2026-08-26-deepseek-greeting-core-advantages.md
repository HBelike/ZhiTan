# DeepSeek 招呼语核心优势选材设计

## 目标

调整传给 DeepSeek V4 Pro 的 Prompt，使模型在完整阅读简历后优先识别并表达候选人的学历、工作经验、个人项目和有区分度的奖项，同时继续根据完整 JD 调整侧重点。

## 设计边界

- 仅修改 Prompt 与对应测试，不增加固定文案模板，不改变生成 API、JSON 协议、模型选择和前端流程。
- 固定使用 `deepseek-v4-pro` 与 `temperature=0.2`。
- 学历、工作经验、个人项目、奖项都必须来自当前简历证据；没有证据的类别必须省略。
- JD 只能用于确定岗位关注点，不能用于证明候选人具备某项能力。
- 示例只展示选材顺序、信息密度和表达方式；示例中的学校层次、年限、公司、项目、网址、技术和成果不得迁移到真实输出。
- 保留现有证据编号、事实、数字、URL、技术词和相似度校验。

## 生成策略

1. 在内部完整扫描全部 CV 证据，并按学历、工作经验、奖项、个人项目、岗位相关技能与成果分类。
2. 从存在证据的类别中选择 2 至 4 项最强优势；有证据时优先覆盖学历、工作经验和个人项目，有区分度的奖项可加入。
3. 避免用同一个工作项目的多项技术细节占满全文；在篇幅允许时覆盖至少两个不同优势类别。
4. 根据 JD 决定优势的排序和措辞，不使用固定句式。
5. 输出前逐项核对所有候选人事实与简历证据编号。
