浏览器助手安装教程

三分钟连接你的浏览器工作台

浏览器助手在你的电脑上读取已登录的 BOSS 岗位信息或小红书面经页面，再交给对应功能使用。无需提供站点密码，也不会上传 Cookie。

安装前先解压：不要直接在 ZIP 里打开文件。请把整个文件夹解压到固定位置，安装完成后也不要移动或删除。

Google Chrome 教程Microsoft Edge 教程
C

Google Chrome

适用于桌面版 Chrome。请在安装期间保留本教程页面。

01

打开扩展管理页

复制地址，在 Chrome 地址栏打开。

chrome://extensions
02

开启开发者模式

打开页面右上角的“开发者模式”开关。

开发者模式
03

加载解压后的文件夹

点击“加载已解压的扩展程序”，选择刚才解压的文件夹。所选文件夹里应直接看到 manifest.json。

加载已解压的扩展程序
find-job-boss-helper
04

刷新生产页面

确认扩展卡片已启用，再回到职位库刷新页面。右上角出现“助手已连接”即可开始搜索。

助手已连接 · v0.2.2
E

Microsoft Edge

适用于桌面版 Edge。扩展包与 Chrome 使用同一个 ZIP。

01

打开扩展管理页

复制地址，在 Edge 地址栏打开。

edge://extensions
02

开启开发人员模式

打开页面左侧的“开发人员模式”开关。

开发人员模式
03

加载解压缩的扩展

点击“加载解压缩的扩展”，选择刚才解压的文件夹。所选文件夹里应直接看到 manifest.json。

加载解压缩的扩展
find-job-boss-helper
04

刷新生产页面

确认扩展已开启，再回到职位库刷新页面。右上角出现“助手已连接”即可开始搜索。

助手已连接 · v0.2.2

安装后仍未连接？

按顺序检查以下三项，然后刷新职位库页面。

  • 扩展文件夹没有被移动或删除
  • 扩展管理页中的开关保持开启
  • 同一浏览器中已经登录 BOSS 直聘

浏览器助手只接受 your-domain.example 的调用，不读取或上传你的 BOSS Cookie、密码与简历。
