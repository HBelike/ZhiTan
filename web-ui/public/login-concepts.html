C · 面试索引

最克制

偏专业工具的浅色索引卡风格，信息密度恰当、易于长期使用；适合作为个人作品站和职业档案入口。

设计选择：我刻意避开了通用的“居中白卡 + 渐变背景”登录页。A 把职业路径做成品牌符号；B 把 Agent 调度感做成空间语言；C 则把面试资料库的“索引”变成视觉结构。
